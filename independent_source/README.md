# Independent resource source files

This is a PUBLIC repository. Files committed here can be downloaded immediately via GitHub, even before appearing on the website. **Only add files when their public release is approved.**

Supported formats: PDF, XLSX, XLSM and ZIP. Package standalone HTML tools into ZIP files so that submitted HTML does not execute on the website origin.

Register each item in `config/independent.json`; the builder generates its public page and download path. Unpublished entries must not include unencrypted files in this directory.
